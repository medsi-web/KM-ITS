# Local API workflows

Import `Local.postman_environment.json` and the collections into Postman. `KMITS.postman_collection.json` probes every declared operation anonymously. `Auth.postman_collection.json` runs the complete local password and Archive workflow. `Archive.postman_collection.json` runs the Archive subset with a real operator login. Both workflows deliberately mutate disposable data and refuse non-localhost origins.

Use a fresh MongoDB replica-set database with authentication and Archive indexes initialized. Bootstrap a super admin with a private username/password. Set the environment variables `baseUrl`, `username`, `password`, `newPassword` and `ingestionSecret` only in a private local environment; do not export their values into source control. Register `http-test-stream`, `http-folder` and `http-ministry` in ARCHIVE_SOURCE_CONFIG for the fixture. Leave the three Drive-reader credentials unset so the PDF-open case asserts DRIVE_NOT_CONFIGURED rather than contacting Google. The fixtures are observations only; no real Drive files or Apps Script deployment is required.

The complete workflow logs in through POST /api/auth/login, reads the 24-hour session, exercises CSRF, creates a temporary account, verifies restricted access, changes its password and signs in again. It then resets that account, verifies session revocation, synchronizes a document twice, checks public metadata, hides and restores visibility, inspects sync logs, checks reserved operations, disables the temporary account and logs out. Cookie jars and redirects are disabled; scripts explicitly capture session cookies and CSRF tokens. Temporary passwords are only retained in the local run environment.

For an automated disposable run, build the application first, then run `pnpm --filter @kmits/backend test:http`. The runner starts a MongoDB memory replica set and Next production server on a free loopback port, creates random private credentials, uses actual HTTP login through Newman and removes its temporary infrastructure afterwards. It does not inject sessions, touch a live database or print credential-bearing responses. A build must reflect the current source. The runner requires permission to spawn MongoDB and Node processes.

The anonymous probe collection expects an initialized archive database. Set `readyExpectedStatus` to 200 for a ready local server or 503 when unavailable. Set `integrationProbeStatus` to 401 with the server integration secret configured, or 503 when absent. `loginExpectedStatus` defaults to 401 for deliberately invalid credentials. Use the full runner for repeatable configuration.

Generate committed artifacts with `pnpm --filter @kmits/backend api:generate`. `backend/openapi.json` describes implemented local auth and Archive operations; Articles and Timeline remain explicitly reserved. Successful Archive opening is a verified 302 redirect; missing reader configuration is 503. No login OAuth flow or approval/rejection state is part of this API.

Validation commands are documented for later execution. Generation does not run tests or contact a database.
